CUADRILLA ALFA: CCTV Básica

> MANUAL DE PROCEDIMIENTO

Objetivo: Implementar 3 cámaras IP en el pabellón de Enseñanza Básica conectadas a un NVR (Network Video Recorder).

  • 01
    Cableado Estructurado: Tirar cable UTP Cat6 desde el Switch PoE (Power over Ethernet) hasta los puntos ciegos del patio. El Switch PoE envía datos y energía por el mismo cable.
  • 02
    Fijación de Hardware: Instalar los domos en el techo (altura min. 3m para evitar vandalismo). Conectar el RJ45 y sellar con caja estanca.
  • 03
    Asignación IP (Software): Entrar a la interfaz web de cada cámara. Cambiar de DHCP a IP Estática (Ej: 192.168.1.101, 102, 103) para que el grabador siempre las encuentre.
  • 04
    Vincular al NVR: En el NVR, agregar las IPs configuradas, ingresar usuario/contraseña de las cámaras y verificar el flujo de video (Main Stream).

CUADRILLA BETA: Redes Oficinas

> MANUAL DE PROCEDIMIENTO

Objetivo: Separar el tráfico de red de la administración de Ed. Media y Ed. Básica para que no puedan verse entre sí (Seguridad de datos).

  • 01
    Concepto de VLAN (Red de Área Local Virtual): Físicamente es el mismo Switch, pero lógicamente lo cortaremos a la mitad mediante software.
  • 02
    Creación de VLANs: Entrar a la consola del Switch Administrable. Crear VLAN 10 (Media) y VLAN 20 (Básica).
  • 03
    Asignación de Puertos (Access Mode): Configurar los puertos donde se conectan los PCs de Media para que solo pertenezcan a la VLAN 10, y los de Básica a la VLAN 20.
  • 04
    Prueba de Conectividad (Ping): Un PC de Media NO debe poder hacer ping a un PC de Básica.

CUADRILLA GAMMA: Mantención

> PROTOCOLO DE MANTENIMIENTO PREVENTIVO/CORRECTIVO

1. Diagnóstico de Hardware (Correctivo): - Verificar temperatura de CPU (Normal: 40-65°C). Si supera 85°C, requiere cambio de pasta térmica urgente.
- Limpieza de ventiladores con aire comprimido.
2. Optimización a Nivel de S.O. (Preventivo): - SFC /scannow: Comando para reparar archivos dañados de Windows.
- Limpieza de Disco: Eliminar archivos temporales (`%temp%`) y caché de actualizaciones que llenan el SSD.
- Gestor de Arranque: Desactivar programas innecesarios que inician con Windows (vía Task Manager).
3. Seguridad: - Análisis completo de malware (Windows Defender o Antivirus de terceros).
- Actualización de parches de seguridad (Windows Update).

CUADRILLA DELTA: Despliegue Lab

> MANUAL: INSTALACIÓN S.O. (FROM SCRATCH)

  1. Preparación del Medio: Crear un Pendrive Booteable con Windows 10/11 utilizando la herramienta Rufus. (Seleccionar esquema de partición GPT para UEFI).
  2. Configuración BIOS/UEFI: Encender el PC, entrar a la BIOS (F2 o DEL). Desactivar Secure Boot (si da problemas) y poner el USB como primera opción en el Boot Priority.
  3. Estructura de Particiones (Crítico en colegios): El disco de 500GB SSD NO debe quedar en una sola partición.
    • Disco C: (S.O. y Programas): ~150GB. Aquí instalaremos Windows. Este disco luego se congelará (Ej: DeepFreeze) para que los alumnos no lo dañen.
    • Disco D: (Datos/Alumnos): ~350GB. Aquí los alumnos guardarán sus trabajos de Word/Excel. No se congela.
  4. Post-Instalación: Instalar drivers gráficos, Office, navegadores web, y finalmente activar el software congelador en el Disco C.
